# 02: Starting Gold

**What to build:** Every new character starts with a fixed 20 Gold, and the player can see it in their character stats in any of the four languages. Gold is not rolled, has no race or occupation modifier, and does not appear in the combat stats. See the spec at `.scratch/merchant-encounter/spec.md`.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] A newly created character has 20 Gold.
- [ ] The character stats show a Gold line, labelled in English, Spanish, French and Italian.
- [ ] The combat stats do not show Gold.
- [ ] The existing "Italian has the same keys as English" test is generalised so every language must have every key English has, and it passes.
- [ ] All existing tests pass.
